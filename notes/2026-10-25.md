### Lecciones

1. El cliente stdio de MCP (`StdioServerParameters`) no hereda el env completo:
   pasar `env=dict(os.environ)` si el server depende de variables propias
   (fue el único fallo de CI).
2. Nombres de módulos de bibliotecas: MCAD usa camelCase (`roundedBox`), BOSL2
   `cuboid`; verificar con el nombre real antes de concluir que la lib no carga.
3. Para workflows en GitHub con token OAuth sin scope `workflow`, empujar por SSH.
